# Pesos U-Net Dust

Os pesos dust8_19.pth e dust16_19.pth foram preservados do repositório jvanvugt/pytorch-unet já incorporado ao projeto original.

Eles usam a arquitetura descrita em manifest.json e são carregados localmente para geração de máscaras de poeira. A licença MIT original está em models/architectures/unet_dust/LICENSE.

O manifesto registra tamanho e SHA-256 para detectar alteração ou corrupção dos arquivos.
